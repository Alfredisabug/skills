# Skills

All skills are included in the `skills` directory.

The other directories relate to my personal development setup — they're templates, not prompts.

- `./implements`: Intermediate states from AI-executed plans
- `./plans`: Plan files generated by AI
- `./prompts`: Frequently used prompts (`*.prompt.md`)
- `./rules`: Project-specific rules and guidelines

---

## 🚀 如何在其他專案中使用 (Quick Link to Project)

進入你的目標專案根目錄，執行此儲存庫中的掛載腳本：

### Windows (PowerShell)
```powershell
# 在目標專案目錄執行：
& <skills庫路徑>\link.ps1

# 若要移除掛載：
& <skills庫路徑>\link.ps1 -Clean
```

### Linux / macOS (Bash)
```bash
# 在目標專案目錄執行：
bash <skills庫路徑>/link.sh

# 若要移除掛載：
bash <skills庫路徑>/link.sh --clean
```

### ✨ 自動完成的事項
1. 建立 `.agents` 軟連結/Junction（支援 Antigravity / Gemini 原生動態技能）。
2. 建立 `AGENTS.md` 技能路由表。
3. 建立 `.github/copilot-instructions.md`（讓 VS Code Copilot 自動依任務讀取 Skill）。
4. 建立 `.github/prompts`（讓 VS Code Copilot Chat 原生選單出現 `*.prompt.md`）。
5. **自動偵測 Git 儲存庫**並將上述設定寫入 `.gitignore`，避免個人 skills 意外被 commit 提交。
